# BharatQuery Cockpit (Frontend)

The frontend client for **IndicSQL** is an accessible, bilingual citizen cockpit built with **Next.js 14**, **TailwindCSS**, and **Vega-Lite**.

## Planned Features:
- **Speech-to-Text Input**: Integrated with Bhashini & Whisper for spoken queries in 7 Indian languages.
- **Dynamic Language Switcher**: Devanagari, Bengali, Tamil, Telugu, and English script interfaces.
- **SQL Preview & Explain Mode**: Interactive SQL visualization, highlighting mapped columns and JOIN operations.
- **Auto-Generated Visualizations**: Vega-Lite / Chart.js bar and line charts dynamically rendered from tabular aggregates.
- **Live LangGraph Trace**: Step-by-step progress visualizer showing query normalization, schema linking, SQL synthesis, and execution metrics.
